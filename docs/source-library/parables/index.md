# Parables

A parable is not converted directly into a list of virtues or physical properties of an ethos. Analysis first identifies the narrated actors, relation, decision, resource, consequence, and point of comparison stated by the Gospel. Only then may it propose an ethos declaration, and figurative details not used by the narrative remain unassigned.
