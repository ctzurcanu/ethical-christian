# By New Testament Book

This index preserves corpus differences while directing each witness to the correct ethos layer.

| Corpus | Primary use in this project |
| --- | --- |
| Matthew | witness to Jesus' teaching, correction, representation, governance, and intended post-resurrection continuity |
| Mark | witness to Jesus' mission, conflict, proof, boundary encounters, and servant authority |
| Luke | witness to Jesus' resource, outsider, reciprocity, mission, and membership rules |
| Acts | formation and institutional enactment of the post-death ethos of Christ |
| John | distinct witness to Jesus' sender relation, friendship, testimony, departure, service, and post-death continuity |
| Romans, 1–2 Corinthians, Galatians, Philippians, 1 Thessalonians, Philemon | central witnesses to the Pauline upgrade, read as distinct letters |
| Other letters attributed to Paul | Pauline-tradition evidence with authorship status attached to each claim |
| James, 1–2 Peter, 1–3 John, Jude, Hebrews | non-Pauline witnesses to the ethos of Christ or, where demonstrated, a later constitutive development |

Book order is not ethos order. A Gospel's post-resurrection scene can belong at the Jesus/Christ boundary, while a later letter may preserve earlier tradition. Revelation is outside this project's present scope.
